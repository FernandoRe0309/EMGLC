Configurar publicación

El botón Publicar sube los cambios al repositorio de GitHub donde vive esta página. Solo funciona con un token de alguien con permiso de escritura en ese repositorio.

¿Cómo creo el token?
  1. En GitHub: tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Resource owner: la organización de la empresa. Repository access: solo este repositorio.
  3. Permissions → Repository permissions → Contents: Read and write.
  4. Si la organización usa inicio de sesión corporativo (SSO) o pide aprobación de tokens, autorízalo o espera la aprobación.

El token se guarda solo en este navegador. No lo compartas ni lo uses en computadoras públicas.
